# Principes et commandes du projet

À compléter à la création du projet. Garde uniquement ce qui est vrai et vérifiable.

## Commandes
Ces commandes servent de critère de succès (voir AGENTS.md §4) : lance-les avant de conclure une tâche de code.
| Action | Commande |
|---|---|
| Tests | `à compléter` |
| Lint / format | `à compléter` |
| Build / lancement | `à compléter` |

## Principes non négociables
Règles propres à ce projet, que l'IA ne doit jamais enfreindre. Exemples à remplacer :
- À compléter : une règle par ligne, formulée de façon vérifiable (« Aucun secret dans le code », « Toute fonction publique a un test »).

## Conventions de code
- À compléter : nommage, structure des dossiers, gestion des erreurs, style.

## Interdits
- À compléter : bibliothèques à ne pas utiliser, fichiers à ne pas modifier, commandes à ne pas lancer.
